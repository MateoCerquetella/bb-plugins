The version triple is consistent (plugin manifest 0.2.0, lockfile 0.2.0, tag tree 0.2.0), the tag is annotated and sits exactly on the merged `main` tip, which fixes the 0.1.1 defect of tagging an unmerged branch, and the documented `@^0.2.0` range is valid semver for a 0.x line (>=0.2.0 <0.3.0), so `^0.1.0` installs are deliberately not auto-upgraded.
