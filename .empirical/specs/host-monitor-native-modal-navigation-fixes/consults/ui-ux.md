# UI/UX Specialist Advisory

- Specialist: ui-ux
- Verdict: advisory

## Findings

### Finding 1

- Severity: high
- Category: navigation
- Location: Open Host Monitor
- Recommendation: reuse BB's native nav-row action and preserve document state;
  never reload or route through Settings.

### Finding 2

- Severity: high
- Category: sidebar hierarchy
- Location: main navigation
- Recommendation: keep only the bottom quick-access icon visible. Hide the
  exact route row reversibly and leave every unrelated row untouched.

### Finding 3

- Severity: medium
- Category: threshold communication
- Location: CPU/RAM mini-modal metrics
- Recommendation: combine semantic color with “above guide” accessible wording;
  avoid alert icons, badges, animation, or alarming copy.

### Finding 4

- Severity: medium
- Category: native styling
- Location: modal and dashboard
- Recommendation: match BB's compact 28px controls, 6px radii, one-pixel token
  borders, muted metadata, clear focus rings, and restrained selected states.
