## Security / correctness

Typed RPC schemas, public-SDK boundaries, bounded errors, and storage validation are sound improvements. Release correctness is nevertheless blocked by the 500-host truncation, removal of Host Monitor CLI surfaces still required by Touch Bar, and a native BBCommand implementation that can block indefinitely on process termination or descendant-held stdout pipes.

## Design / maintainability

The typed host adapter, pure selection reconciler, host-owned picker, and semantic overlay variables are maintainable and align with D-001. Maintainability is undermined by stale duplicated release documentation, missing committed marketplace artifacts, and an unversioned cross-plugin CLI dependency that was removed without updating its Touch Bar consumer or adding an integration contract.
