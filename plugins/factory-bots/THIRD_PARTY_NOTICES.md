`vendor/mascot/orb-core.js` and its type declarations are the Agent Orb Core
from [do.computer](https://github.com/SawyerHood/do-computer), MIT licensed,
copyright Sawyer Hood. The plugin vendors the r128-compatible orb renderer so
each agent card can show the same creature.

`vendor/mascot/wardrobe.js` is the Agent Orb Wardrobe from the same project, and
`lib/wear-items.ts` is its companion gift list from do.computer's protocol
package, also MIT licensed. They let an agent's creature open a real gift and
wear what it finds.
