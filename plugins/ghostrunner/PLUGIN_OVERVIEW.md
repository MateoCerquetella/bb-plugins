## Neon on black

Ghostrunner turns BB into a cyberpunk console. It uses near-black panels with a hot red accent, cyan for success and diffs, and yellow for warnings. Text is set in JetBrains Mono and titles in Chakra Petch, when those fonts are installed.

Select Ghostrunner in Settings → Appearance. It is dark only, so Light, Dark and System modes all show the same palette. A matching syntax theme covers code and diffs.

The plugin ships colours only, with no wallpapers, network requests or stored data. To add a background, pair it with Aura.
