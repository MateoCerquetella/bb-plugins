## Ghostrunner

Ghostrunner turns BB into a cyberpunk console. It offers near-black Dark panels and cool-gray Light panels, with red accents, cyan for success and diffs, and yellow for warnings. Text is set in JetBrains Mono and titles in Chakra Petch, when those fonts are installed.

Select Ghostrunner in Settings → Appearance. Light and Dark use matching palettes for the app, code and diffs. System follows your device appearance.

The plugin ships colours only, with no wallpapers, network requests or stored data. To add a background, pair it with Aura.
